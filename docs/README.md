# Documentation

This directory explains the purpose, methodology, ethical boundaries, data-handling expectations, and terminology used in the Indonesia OSINT & PII Protection Framework.

## Documents

- [`project-overview.md`](project-overview.md): project goals, scope, audience, and deliverables.
- [`methodology.md`](methodology.md): end-to-end workflow separating data criticality from exposure risk.
- [`criticality-vs-exposure-risk.md`](criticality-vs-exposure-risk.md): explains the two dimensions with synthetic examples.
- [`ethical-osint-principles.md`](ethical-osint-principles.md): rules for lawful, privacy-conscious OSINT.
- [`data-handling-policy.md`](data-handling-policy.md): safe handling, storage, redaction, retention, and deletion guidance.
- [`glossary.md`](glossary.md): terms and Indonesia-specific identifiers used in this repository.

## Important note

This repository is an educational and defensive framework. IPCR and the Exposure Risk Score (ERS) are proposed project methods, not official Indonesian government classifications, legal opinions, compliance certifications, or substitutes for an organization's own security and privacy processes.
